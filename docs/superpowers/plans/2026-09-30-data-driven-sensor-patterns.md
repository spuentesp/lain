# Data-driven sensor patterns — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor the contract-federation sensors' per-framework detection patterns from hardcoded Rust match arms and tree-sitter node checks into data files (one `.scm` + one YAML entry per framework), so adding a new framework becomes a data change, not a Rust change.

**Architecture:** Two-tier model — Camp A: regex/text patterns in `src/server/sensors/patterns/frameworks.yaml` (loaded at runtime); Camp B: tree-sitter structural patterns in `src/server/sensors/patterns/<lang>/*.scm` (compiled at build time via `tree-sitter-cli`). Org-specific overrides load at runtime from `<repo>/.lain/patterns/`. Per-language walker dispatch arms in `field_access_sensor.rs` stay in Rust (rules 1-6 are language-specific semantics).

**Tech Stack:** Rust 1.98+, tree-sitter 0.25 + tree-sitter-{python,javascript,typescript,rust,go,java,c-sharp,ruby,kotlin-ng}, serde + serde_yaml, tree-sitter-cli (build-dependency), thiserror.

**Spec:** [`docs/superpowers/specs/2026-09-30-data-driven-sensor-patterns-design.md`](../specs/2026-09-30-data-driven-sensor-patterns-design.md)

## Review Focus

Failure modes the spec implies but no single task's tests cover:

1. **Tree-sitter query syntax bugs in `.scm` files** — pin with per-pattern regression tests in Task 1 (compile step catches them at build, but capture-name mismatches are runtime).
2. **YAML schema drift** (Camp A) — pin in Task 1 with a schema-validation test on the bundled `frameworks.yaml`.
3. **Runtime override path failing silently** — pin in Task 7 with an end-to-end override test that asserts org files REPLACE (not augment) bundled entries by `id`.
4. **Adding a new framework as a data-only change** — pin in Task 8 (proof task).
5. **`field_access_sensor.rs` walker semantics unchanged** — pin by the existing `field_access_sensor` test suite (regression; do not change walker code).

- [ ] **Step 1.4: Implement `Patterns::from_yaml_str` + `Patterns::load_default`** — in the same `mod.rs`:
  ```rust
  use std::sync::OnceLock;

  #[derive(Debug)]
  pub struct Patterns {
      yaml: YamlFile,
      overrides_applied: bool,
  }
  impl Patterns {
      pub fn from_yaml_str(s: &str) -> Result<Self, serde_yaml::Error> {
          Ok(Self { yaml: serde_yaml::from_str(s)?, overrides_applied: false })
      }
      pub fn from_yaml_file(path: &Path) -> Result<Self, ...> { /* serde_yaml::from_reader */ }
      pub fn load_default() -> &'static Self {
          static P: OnceLock<Patterns> = OnceLock::new();
          P.get_or_init(|| Self::from_yaml_str(include_str!("frameworks.yaml")).expect("bundled yaml"))
      }
      pub fn framework(&self, id: &str) -> Option<&FrameworkDef> {
          self.yaml.languages.values().flat_map(|v| v.iter()).find(|f| f.id == id)
      }
      pub fn route_patterns(&self, lang: Lang) -> impl Iterator<Item = &FrameworkDef> {
          self.yaml.languages.get(&lang_key(lang)).into_iter().flatten().filter(|f| f.kind == FrameworkKind::Route)
      }
      pub fn outbound_patterns(&self, lang: Lang) -> impl Iterator<Item = &FrameworkDef> {
          self.yaml.languages.get(&lang_key(lang)).into_iter().flatten().filter(|f| f.kind == FrameworkKind::Outbound)
      }
      pub fn deny_methods_for(&self, lang: Lang, lib: &str) -> Vec<String> {
          self.yaml.languages.get(&lang_key(lang)).into_iter().flatten()
              .filter(|f| f.kind == FrameworkKind::Outbound)
              .filter(|f| f.lib_match.as_deref().map_or(true, |re| regex_match(re, lib)))
              .flat_map(|f| f.deny_methods.iter().cloned())
              .collect()
      }
      pub fn load_overrides(&mut self, root: &Path) -> Result<(), ...> {
          let p = root.join(".lain/patterns");
          if !p.exists() { return Ok(()); }
          let y = YamlFile::load_from_dir(&p)?;
          for (lang, list) in y.languages {
              for new_def in list {
                  if let Some(existing) = self.framework_mut(&new_def.id) {
                      *existing = new_def;
                  } else {
                      self.yaml.languages.entry(lang).or_default().push(new_def);
                  }
              }
          }
          self.overrides_applied = true;
          Ok(())
      }
      fn framework_mut(&mut self, id: &str) -> Option<&mut FrameworkDef> {
          self.yaml.languages.values_mut().flat_map(|v| v.iter_mut()).find(|f| f.id == id)
      }
  }
  fn lang_key(lang: Lang) -> &'static str { match lang { Lang::Python => "python", ... } }
  ```
